# ستون‌های نسخهٔ اولیهٔ داده

نسخهٔ eda-v1 برای EDA و آماده‌سازی ویژگی‌های زبانی ساخته شده است. فایل‌های فردی در `data/analysis/eda-v1/` قرار می‌گیرند. قواعد ورود در `data_v1_rules.json` و منشأ فایل‌ها و شمارش‌ها در `data_v1_manifest.json` ثبت می‌شوند.

## users.csv

هر سطر یک کاربر یکتا است.

| ستون | معنا |
|---|---|
| user_key | کلید مستعارِ مشترک با پروفایل‌های قبلی، BLAKE2b با طول ۱۶ بایت و نمایش hex |
| split | بخش آموزش، اعتبارسنجی یا آزمون با هش ثابت کاربر |
| eligible_reviews | تعداد کتاب‌های متمایزِ دارای بدنهٔ منتخب با حداقل ۲۰ توکن |
| eligible_tokens | مجموع توکن‌های بدنه‌های منتخب، پس از حذف متن‌های کوتاه |
| genres | عضویت‌های ژانری کاربر، با جداکنندهٔ عمودی؛ یک کاربر می‌تواند چند عضویت داشته باشد |

## memberships.csv

هر سطر یک جفت کاربر–ژانر است. این جدول شواهد گرایش در کل سابقه را نگه می‌دارد. تعداد کتاب‌های این جدول پیش از فیلتر کوتاهی متن محاسبه شده است.

| ستون | معنا |
|---|---|
| user_key، split | اتصال به جدول کاربران |
| genre | گروه گرایش رفتاری کاربر |
| distinct_books | تعداد parent_asin متمایز در این ژانر در کل سابقه |
| share_all_books | نسبت کتاب‌های ژانر به تمام کتاب‌های متمایز نقدشدهٔ کاربر |
| share_mapped_books | نسبت کتاب‌های ژانر به تمام کتاب‌های دارای نگاشت معتبر در هفت گروه |
| mapping_coverage | نسبت کتاب‌های قابل‌نگاشت به کل سابقهٔ کتاب‌های متمایز |
| dated_books | تعداد کتاب‌های ژانر با تاریخ معتبر |
| active_quarters | تعداد سه‌ماهه‌های تقویمی فعال با مبنای UTC |
| span_days | فاصلهٔ اولین و آخرین نقدِ نخستینِ کتاب‌های متمایز ژانر، برحسب روز |

## reviews.jsonl.gz

هر سطر یک شیء JSON برای یک جفت کاربر–کتاب است. عضویت چندژانری در جدول عضویت می‌ماند و باعث تکثیر سطر نقد نمی‌شود. انتخاب نقد بر اساس طول بدنه و سپس کمترین هش محتوای رکورد انجام می‌شود.

| فیلد | معنا |
|---|---|
| user_key، split | اتصال به جدول کاربران و بخش ثابت فرد |
| parent_asin | شناسهٔ کتاب برای اتصال و ممیزی تکرار |
| book_genre | ژانر کتاب از نگاشت فعلی؛ برای کتاب مبهم یا بدون نگاشت null است |
| text | بدنهٔ اصلی نقد منتخب با حفظ قالب، نشانه‌گذاری و حروف |
| tokens | طول بدنه با الگوی واژه‌شماری ممیزی قبلی؛ دست‌کم ۲۰ |
| timestamp | زمان ثبت همان رکورد نقد برحسب میلی‌ثانیهٔ Unix؛ مقدار نامعتبر null می‌شود |
| rating | امتیاز همان رکورد از ۱ تا ۵؛ مقدار نامعتبر null می‌شود |
| verified_purchase | وضعیت خرید تأییدشده در همان رکورد، یا null |
| helpful_vote | تعداد رأی مفیدبودن نامنفی در همان رکورد، یا null |
| source_row | شمارهٔ سطر یک‌مبنایی در آرشیو خام برای ردیابی |

امتیاز و زمان نقد منتخب ممکن است با امتیاز آخر یا تاریخ اولین کتاب در پروفایل گرایش فرق داشته باشد، چون قاعدهٔ انتخاب متن با قاعدهٔ خلاصه‌سازی سابقه متفاوت است. این فیلدها مقدار همان رکوردی هستند که متن از آن انتخاب شده است.

شناسه‌ها، شمارهٔ سطر و برچسب عضویت برای اتصال و ممیزی‌اند. بازنمایی زبانی از متن استخراج می‌شود. نقش ژانر کتاب و سایر متغیرها در مقایسه و مدل‌سازی باید جداگانه تعریف شود.

## مدیریت کیفیت و گام بعد

متن فاقد نوع رشته‌ای و شناسهٔ کتاب نامعتبر وارد نمونهٔ نقد نمی‌شوند. متن کوتاه طبق قاعده حذف و کفایت متن هر کاربر دوباره سنجیده می‌شود. فیلد عددی یا زمانی نامعتبر به null تبدیل می‌شود. برای برازش ویژگی‌های بعدی، برخورد با دادهٔ گمشده براساس کاربرد هر فیلد تعیین خواهد شد.

در EDA آموزش، زبان متن، HTML، متن‌های بسیار بلند، تکرار متن بین کاربران و توزیع تعداد نقدهای هر فرد بررسی می‌شوند. سپس نسخهٔ پردازش‌شده با قواعد ثبت‌شده برای TF-IDF، ویژگی‌های سبکی، کاهش بُعد و خوشه‌بندی ساخته خواهد شد. نسخهٔ خامِ منتخب امکان بازبینی تصمیم‌های پردازش را فراهم می‌کند.
