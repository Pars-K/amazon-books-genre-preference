# تحویل فاز دوم

[ممیزی شواهد آماری و تکرار در کاربران جداگانه](validity/report-fa.md) میزان اتکاپذیری خوشه‌ها، واژه‌ها و هر ۲۹ شاخص را بررسی می‌کند. این ممیزی پس از تحلیل اکتشافیِ نسخهٔ اولیه انجام شد و برای تفسیر نتیجه‌های آن باید خوانده شود.

[گزارش فارسی](report-fa.md) و [نسخهٔ PDF](../phase2.pdf) مسیر استدلال، نتیجه‌های اصلی، محدودیت‌ها و تطبیق با الزامات درس را ارائه می‌کنند. سؤال ۱۰ فاز اول مبنای هدف پروژه است.

## اجرای کامل

از ریشهٔ مخزن، با Python 3.14 و وابستگی‌های ثبت‌شده در requirements.txt اجرا کنید.

```console
python src/run_phase2.py --rebuild
```

این فرمان همهٔ مراحل را به ترتیب اجرا می‌کند و در پایان آزمون‌ها، بازتولید ویژگی متن و منشأ داده را کنترل می‌کند. خواندن آرشیو نقدها و فراداده زمان‌بر است. خروجیِ فردی و بازنمایی‌های ذخیره‌شده زیر `data/analysis/phase2-final/` هستند. گزارش‌های تجمیعی زیر `reports/phase2/patterns/` قرار می‌گیرند. فرمان زیر صحت نسخهٔ موجود را بررسی می‌کند.

```console
python src/run_phase2.py --verify
```

برای فقط ساخت مجدد گزارش از نتیجه‌های عددی موجود، اجرا کنید.

```console
python src/build_phase2_report.py
```

## اندازه‌گیری متن تازه

```console
python src/phase2_transform.py --text "I enjoyed this story. I could not put it down!"
```

خروجی شامل ۲۹ شاخص نوشتاری، تعداد واژه‌ها، شاخصِ وجود نقل‌قول، پوشش واژگان و مختصات SVD است. این تبدیل همان پارامترهای واژگانیِ ذخیره‌شدهٔ توسعه را استفاده می‌کند. نقدی که هیچ واژهٔ شناخته‌شده‌ای ندارد بردار واژگانی صفر می‌گیرد. کاربرد گرایش‌سنجی به ارزیابی مدل پیش‌بینی در فاز سوم وابسته است.

## حدود روش

هدف پیش‌بینی، گرایش نویسنده است. ژانر کتاب، امتیاز، قیمت و تاریخ برای تحلیل و تفسیر نگه داشته می‌شوند. مقایسه‌های بیرونی از برچسب‌های مبتنی بر کتاب‌های دیگر استفاده می‌کنند. در مقایسهٔ تقویت‌شده، کتاب ورودی خارج از گرایش اصلی هر دو گروه است و حذف آن شواهدِ گرایش اصلی را حفظ می‌کند.

انتخاب پارامتر و تمام برازش‌های این دور روی توسعه انجام شده‌اند. آستانهٔ ورود به داده، نامتوازنی گروه‌ها، تعداد اندک فلسفی، برچسب رفتاری و پوشش محدود روش‌های واژگانی، دامنهٔ استنباط را محدود می‌کنند. بازه‌های بوت‌استرپ و مقایسه‌های جابه‌جایی اکتشافی‌اند. از همبستگی و خوشه‌بندی، دقت پیش‌بینی کاربر تازه به دست نمی‌آید.

چارچوب آماده‌سازی با NumPy، SciPy و pandas پیاده شده است. TF-IDF دارای وزن فراوانی لگاریتمی، IDF هموارشده و نرمال‌سازی L2 است. کد SVD تصادفی با بازسازی ماتریس کم‌رتبهٔ معلوم کنترل شده است. فرمول سیلوئت و شاخص رند نیز روی مثال‌های دارای پاسخ معلوم آزموده شده‌اند. پارامترها و بذرها در کد و خروجی‌ها ثبت شده‌اند.
